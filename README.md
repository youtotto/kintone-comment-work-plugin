# コメントワーク（Comment Work）

kintone のコメントを、業務の記録としてもっと使いやすくする無料の kintone プラグインです。よく使うコメントのテンプレート、レコードの値の差し込み、ステータスが変わったときのコメントが使えます。

- 🆓 無料・MIT License
- 🖥 kintone PC 版のレコード詳細画面で動作

## ダウンロードと導入

[Releases](https://github.com/youtotto/kintone-comment-work-plugin/releases/latest) から次のファイルをダウンロードします。

| ファイル | 用途 |
|---|---|
| `comment-work-2.0.0-free-bundle.zip` | 説明書付きの配布用 ZIP（おすすめ）。**ZIP を解凍し、中の `comment-work-2.0.0-free-plugin.zip` を kintone へ読み込みます。bundle 自体は kintone に直接読み込みません** |
| `comment-work-2.0.0-free-plugin.zip` | kintone に直接読み込むプラグイン（bundle の中身と同じファイル） |
| `SHA256SUMS.txt` | 上記 ZIP の SHA-256 |

kintone への読み込みは、kintone システム管理 →「プラグイン」→「読み込む」で `comment-work-2.0.0-free-plugin.zip` を ZIP のまま選びます。

## 主な機能

- **コメントテンプレート**: よく使うコメントを登録し、レコードの詳細画面のボタンから一覧を開いて選べます。名前・本文で絞り込めます
- **レコード値の差し込み**: 本文に `{{フィールドコード}}`（フィールドの値）、`{{$today}}`（今日の日付）、`{{$now}}`（現在の日時）、`{{$user}}`（ログインユーザー）、`{{$id}}`（レコード ID）を差し込めます
- **コメント欄への入力・投稿前の内容確認・コピー**: 「コメント欄に入れる」「確認して投稿」「コピー」から選べます。宛先（メンション）も付けられます
- **ステータス連動コメント**: プロセス管理のアクションでステータスが変わったとき、その記録をコメントに投稿します。`{{$action}}`（実行したアクション）、`{{$fromStatus}}`・`{{$toStatus}}`（変更前後のステータス）、`{{$assignees}}`（次の作業者）を本文に入れられ、次の作業者を宛先にすることもできます
- **投稿できていない記録**: 通信の失敗などで投稿できなかった本文を残し、あとから内容を確かめて投稿・コピーできます
- **取り込み・書き出し**: テンプレートとルールを JSON で書き出し、別のアプリで取り込めます

有料版の「コメントワーク＋」では、ステータス期間ごとのコメント整理、コメント検索、コメント番号による参照、コメントからフィールドへの移動、アクション実行時の理由入力（試験的な機能）も使えます。同じプラグインなので、プラグインファイルを読み込み直すだけで切り替えられ、アプリの設定はそのまま引き継がれます。

## 使い方

1. kintone のシステム管理 →「プラグイン」→「読み込む」で `comment-work-2.0.0-free-plugin.zip` を ZIP のまま読み込みます
2. アプリの設定 →「プラグイン」で「コメントワーク」を追加し、歯車アイコンから設定画面を開きます
3. テンプレートやステータス連動のルールを作って「保存」し、アプリを更新します
4. レコードの詳細画面のボタン（初期値「コメントテンプレート」）からテンプレートを使います

くわしい使い方は、bundle に入っている `docs/利用者向け説明書.md` をご覧ください。

## 対応環境

- kintone PC 版（レコードの詳細画面、プラグイン設定画面）
- モバイル版には対応していません
- ステータス連動コメントには、アプリのプロセス管理が必要です
