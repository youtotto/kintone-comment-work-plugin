# コメントワーク 2.0.0 リリースノート

kintone のコメントを、業務の記録としてもっと使いやすくする無料のプラグイン「コメントワーク」を公開しました。

### 主な機能

- コメントテンプレート（名前・本文で絞り込み、宛先の付与）
- レコード値の差し込み（フィールドの値、今日の日付、現在の日時、ログインユーザー、レコード ID）
- コメント欄への入力・投稿前の内容確認・コピー
- ステータス連動コメント（対象のアクションでステータスが変わったときに投稿。作業者全員の承認が必要なステータスでは、最後の承認でステータスが変わったときに投稿）
- 投稿できなかった本文を「投稿できていない記録」に残し、あとから投稿・コピー
- テンプレートとルールの取り込み・書き出し（JSON）

### コメントワーク＋ との関係

- 有料版「コメントワーク＋」・「[試用版] コメントワーク＋」と同じプラグインです。プラグインファイルを読み込み直すと入れ替わり、アプリの設定は引き継がれます
- ＋の設定（パネル・理由の入力）は、無料版で保存しても残ります

### 対応環境

- kintone PC 版のレコード詳細画面（モバイル版には対応していません）
- ステータス連動コメントには、アプリのプロセス管理が必要です
